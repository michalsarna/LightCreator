# 키보드 단축키

macOS에서는 **Ctrl**을 **Cmd**로 읽으십시오. 텍스트 입력 칸에 입력하는 동안에는 키가 입력 칸에 속합니다(복사, 붙여넣기, 삭제, 모두 선택, 한 글자 도구 키는 도면에 작용하지 않습니다). **빠른 안내서**(Quick guide) (**F1**)는 프로그램 안에서 주요 키를 나열합니다. 모든 메뉴 항목과 그 키는 [메뉴](Menus-KO)에 있습니다.

**macOS:** 시스템 메뉴 바는 새로 만들기(New), 열기…(Open…), 저장(Save), 다른 이름으로 저장…(Save as…), SVG 가져오기…(Import SVG…) 옆에만 키를 표시하지만, 아래의 모든 키는 Cmd와 함께 동작합니다. **Cmd+Q**는 LightCreator 메뉴의 **종료**(Quit)입니다.

## 파일

| 단축키 | 동작 |
|---|---|
| Ctrl+N | 새 탭에 새 도면 |
| Ctrl+O | 프로젝트 열기 |
| Ctrl+S | 저장 |
| Ctrl+Shift+S | 다른 이름으로 저장 |
| Ctrl+I | SVG 가져오기 |
| Ctrl+P | 인쇄 |
| Ctrl+Q | 종료 |

## 레이저

| 단축키 | 동작 |
|---|---|
| Ctrl+E | **G-code 내보내기…**(Export G-code…) |
| Ctrl+Shift+P | **미리 보기 창…**(Preview window…) |

## 편집

| 단축키 | 동작 |
|---|---|
| Ctrl+Z | 실행 취소 |
| Ctrl+Y 또는 Ctrl+Shift+Z | 다시 실행 |
| Ctrl+C / Ctrl+V | 복사 / 붙여넣기 |
| Ctrl+D | 복제 |
| Delete 또는 Backspace | 선택 항목 삭제(노드 편집 중에는 선택한 노드) |
| Ctrl+A | 모두 선택 |
| 화살표 키 | 선택 항목을 1 mm씩 이동; **Shift** + 화살표 = 10 mm (제어(Control) 탭에서 **키보드**(Keyboard)가 켜져 있을 때는 제외, 아래 참고) |

## 배치

| 단축키 | 동작 |
|---|---|
| Ctrl+G / Ctrl+Shift+G | 그룹 / 그룹 해제 |
| Ctrl+L / Ctrl+Shift+L | 잠금 / 잠금 해제 |
| N | 노드 편집(노드 도구) |

## 도구

수정 키 없이 한 개의 키입니다. 같은 키가 도구 바의 도움말 풍선과 **삽입**(Insert) 메뉴의 이름에 있습니다.

| 키 | 도구 | 키 | 도구 |
|---|---|---|---|
| V | 선택 | S | 별 |
| N | 노드 편집 | G | 다각형(작은 창에서 변의 개수 설정) |
| R | 사각형 | K | 하트 |
| E | 타원 | I | 나선(작은 창에서 회전 수 설정) |
| Y | 삼각형 | L | 선 |
| P | 폴리라인 / 펜 | T | 텍스트 |
| H | 이동 | Z / X | 확대 / 축소 |

## 키보드로 기계 조그하기

**제어** 탭에서 **키보드**를 켜면(기본값 꺼짐) 키가 선택한 도형 대신 기계를 탭에서 선택한 단계만큼 움직입니다. 연결이 필요합니다.

| 키 | 동작 |
|---|---|
| 화살표 키 | X와 Y를 한 단계씩 조그 |
| Page Up / Page Down | Z를 한 단계씩 조그(Z축이 있는 기계에서만) |

## 열린 도면의 탭

| 단축키 | 동작 |
|---|---|
| Ctrl+1 … Ctrl+9, Ctrl+0 | 열린 도면 중 1번째 … 9번째, 10번째 도면 표시 |
| Ctrl+W | 표시된 도면 닫기(저장하지 않은 작업이 있으면 물음; 마지막 도면을 닫으면 프로그램이 닫힘) |
| Ctrl+N | 새 탭에 새 도면 |

## 보기

| 단축키 | 동작 |
|---|---|
| Ctrl+Shift+0 | 작업 영역을 창에 맞춤(직접 확대·축소할 때까지 맞춘 상태 유지) |
| Ctrl+Shift+9 | 모든 객체에 맞춤 |
| Ctrl++ (또는 Ctrl+=) / Ctrl+- | 보기 중심을 기준으로 확대 / 축소 |
| Space (누르고 있기) | 어떤 도구에서든 화면 이동; 놓으면 사용하던 도구로 돌아감 |
| Escape | 선택 항목과 완성되지 않은 폴리라인 해제(노드 편집 중에는 먼저 선택한 노드) |
| Escape 두 번 | 선택 도구로 돌아감 |
| F1 | 빠른 안내서 |

## 마우스와 터치

| 동작 | 결과 |
|---|---|
| 휠 | 포인터를 기준으로 확대·축소(미리 보기와 카메라 보기에서도) |
| 가운데 또는 오른쪽 버튼 드래그 | 화면 이동(작업 영역과 그 옆에서; 움직이지 않은 오른쪽 클릭은 메뉴를 엶) |
| 핀치(터치패드) | 확대·축소 |
| 클릭; **Shift**+클릭 또는 **Ctrl**+클릭 | 선택; 선택 항목에 추가 / 선택 항목에서 제거 |
| 왼쪽 → 오른쪽으로 영역 드래그 | 완전히 안에 들어간 것을 선택 |
| 오른쪽 → 왼쪽으로 영역 드래그 | 영역에 닿은 모든 것을 선택 |
| 그리는 중 **Shift** | 정사각형, 원 또는 같은 변 |
| 모서리 핸들 드래그 | 비율을 유지하며 크기 조절; **Shift**와 함께면 자유롭게 |
| 회전 중 **Shift** | 15° 단위 |
| 확대·축소 도구와 함께 **Shift** | 반대로 동작: 확대 도구는 축소, 축소 도구는 확대 |
| 선택 항목의 핸들을 다시 클릭 | 크기 조절 핸들과 회전 / 기울이기 핸들 사이 전환 |
| 도형 더블 클릭 | 노드 편집(텍스트와 그림 제외) |
| 구간 더블 클릭(노드 편집) | 노드 추가 |
| 폴리라인 도구: 첫 번째 점 클릭 | 선 닫기 |
| 폴리라인 도구: 오른쪽 클릭, **Enter** 또는 더블 클릭 | 선 끝내기 |
| 오른쪽 클릭(다른 도구) | 배치 명령이 있는 컨텍스트 메뉴(이동 및 확대·축소 도구 제외) |
| 카메라 보기 더블 클릭 | 전체 화면으로 돌아감 |
| 탭 드래그 | 같은 바의 다른 위치나 다른 창 영역으로 이동 |
| 탭 오른쪽 클릭 | **창 영역 N으로 이동**(Move to pane N), **별도의 창에서 열기**(Open in a separate window) (미리 보기, G-code 텍스트, 카메라), **탭 닫기**(Close tab) |
