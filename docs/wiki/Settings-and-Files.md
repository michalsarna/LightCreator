# Settings and Files

Language, colour scheme, device profiles, the last used profile and the window size are stored in a single file, `app.ron`:

| System | Location |
|---|---|
| macOS | `~/Library/Application Support/baseCreator/apps/lightcreator/app.ron` |
| Windows | `%APPDATA%\baseCreator\apps\lightcreator\app.ron` |
| Linux | `$XDG_DATA_HOME/baseCreator/apps/lightcreator/app.ron`, by default `~/.local/share/baseCreator/apps/lightcreator/app.ron` |

* **Shared folder.** LightCreator, MillCreator and PenCreator keep their data in one folder, `baseCreator` (the table shows the program's own settings inside it). The **clipart gallery is shared**: a picture saved or downloaded in one program shows up in the others (the `clipart` folder next to `apps`, with an `index.json` recording name, category, source, licence and author). Each program keeps its own settings, device profiles, materials and tools in `apps/<program>/app.ron`. Set the environment variable `BASECREATOR_DIR` to use another folder.
* The file is written when the application closes. **Delete it to reset everything**; the start window then asks for a device profile again.
* Projects (`.cre`), SVG and G-code are saved wherever you choose. A `.cre` file is shared with MillCreator and other programs on baseCreator: it holds the drawing, the description and one section per program. LightCreator writes its own `laser` section (the machine setup it was made for, the selected material with its layers, the layer order) and keeps the sections of other programs untouched when you save. It never writes your connection, port, cameras or device notes; opening a project made for a different controller, work area or machine zero shows a warning, and the device you have selected stays in use. **File → Open recent** lists the last 10 projects and SVG files you opened or saved (also kept in `app.ron`; **Clear list** empties it; the start window shows the first five). The project file also keeps the notes of the **Description** tab (written into the G-code as `; Note:` comments) and the overlay picture of the camera overlay.
* After saving by hand a **File saved** message shows for 5 seconds. **Settings → Program options…** sets **auto-save** (every 120 seconds by default): work without a file name is written to a temporary folder, a named file is saved in place. Every open drawing has a **tab** above the work area (**File → New**, **Open…** and the **+** of the bar make one, up to 10; a dot marks a tab with unsaved work; Ctrl+1 … Ctrl+0 show them and Ctrl+W closes one). The work area can be split into up to three panes of tabs, see [Design Tools](Design-Tools#view-and-navigation). Closing the program with unsaved work asks, tab by tab, **Save**, **Discard** (deletes the temporary file and quits) or **Cancel** (back to the program).
* **Help → Download backup…** asks where to save a zip with your settings (`app.ron`, as they are now) and the whole shared `clipart` gallery, with a README. **Help → Restore from backup…** reads such a file back (the settings are replaced after a confirmation, the pictures are **added** to the gallery, so nothing saved by MillCreator or PenCreator in the meantime is lost; MillCreator and PenCreator have the same two entries and refuse a backup made by another program); when no profile files are found at start, the start window offers it with a green button.
* **Help → Export diagnostics (zip)…** asks where to save a zip to attach to a bug report: `info.txt` (version, system, device, connection), `device.json` (the device with passwords in addresses hidden), `settings.txt` (without the web server key and the recent files), `console.txt` (what crossed the link to the machine, without the status polls) and `project.cre` (the open project). Look through it before you send it: it holds your design.
* **Updates:** at start the program looks for a newer release on GitHub (**Settings → Program options…** switches that off); **Help → Check for updates…** does it by hand and a newer version opens the page with the packages.
* The window has its **own flat, square frame**: a title bar with the icon, the title and the open file, and minimise / maximise / close buttons. Drag the bar to move the window, double-click it to maximise, resize from the edges (on macOS from the right and bottom edges).
* **Settings** menu: **View options…** (grids, background of the work area, colour of the workspace around it, line thickness, layer names, variable names, preview of the G-code after saving), **Program options…** (auto-save, the update check, the web server and API), **Plugins…**, **Language** (English default) and **Colour scheme** (Dark, Light Dark, Medium Light, Light, and a dark and a light one in blue, green, purple, brown and orange; default Light Dark; around Christmas, New Year's Eve, Halloween and Easter a dark and a light festive scheme are added for the holiday). See [Menus](Menus#settings).
* Interface languages (30): English, Polski, Deutsch, Italiano, Suomi, 中文, हिन्दी and 23 more European languages: Български, Català, Hrvatski, Čeština, Dansk, Nederlands, Eesti, Français, Ελληνικά, Magyar, Íslenska, Gaeilge, Latviešu, Lietuvių, Malti, Norsk bokmål, Português, Română, Slovenčina, Slovenščina, Español, Svenska, Українська. The European texts are in `assets/lang/` (one file per language) and were prepared with machine help, so corrections from native speakers are welcome. Icons are SVG files and fonts (Noto Sans, Mono, SC, Devanagari) are embedded from `assets/`, so the look is identical on every system.

## Status bar and button colours

The status bar at the bottom shows the state of the device (with a dot: green when connected) and of the web server (off, on with its port, or an error). Save buttons are **green**, import buttons **blue** and delete buttons **red** with a bin.

## Printing
**File → Print…** (Ctrl+P; on macOS only from the menu) prints the design on a paper printer. The page is a one-page PDF made by LightCreator: the whole work area to scale (dashed border) or only the objects as large as the page allows; objects on visible layers only, or all; A4 or Letter; a margin of 0–40 mm. The page turns to landscape when the printed part is wider than tall, and a line at the bottom gives the scale. Layers are drawn in their colours, filled shapes lightly tinted, images in grey. A warning appears when objects reach outside the work area (with the work-area option they are cut off at its edge).

**Print** sends the page to the system printer: `lp` on macOS and Linux (with a choice of the printers the system lists) and the *Print* verb of the default PDF viewer on Windows (the default printer). **Save as PDF…** and **Open the PDF** (print from the viewer with more options) are the alternatives. Print preview is the PDF itself. Nothing here has been tried on real printers yet.
