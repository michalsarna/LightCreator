# GRBL 代码

LightCreator 发送给 GRBL 控制器的内容以及控制器的应答。有关 GRBL 的说明均基于 **GRBL 1.1**（大多数二极管激光器运行的固件）；其他版本和分支（grblHAL、FluidNC、厂商构建版本）可能有所不同。仅在 Sculpfun S9 上测试过；程序自身的流式传输已针对 [GRBL 模拟器](GRBL-Simulator-ZH) 进行了测试。

## 实时字符

GRBL 会立即响应的单个字节，即使在作业进行中也是如此。它们不是行，也不会得到 `ok`。

| 字节 | 含义 | LightCreator 中的用途 |
|---|---|---|
| `?` | 状态报告 | 每秒请求四次；应答用于填写状态和位置 |
| `!` | 进给保持 | **暂停**（**Pause**） |
| `~` | 循环启动 / 继续 | **继续**（**Resume**） |
| Ctrl+X (0x18) | 软复位 | **STOP**，以及连接后发送一次，使控制器处于已知状态 |

在运动中软复位后，真实的 GRBL 1.1 会触发 `ALARM:3`（位置丢失），需要 `$X` 或回零。

## 系统命令（`$`）

| 命令 | 含义 | LightCreator 中的用途 |
|---|---|---|
| `$H` | 运行回零循环 | **回零**（**Home**）、连接后的“让机器回零”（"Home the machine"）、在静止时开启 **实时激光位置**（**Live laser Position**） |
| `$HX`、`$HY` | 单轴回零（仅在固件报告支持时） | *X 回零*（*Home X*）/ *Y 回零*（*Home Y*）按钮 |
| `$X` | 解除报警锁定 | **解锁**（**Unlock**）、连接后的“清除报警”（"Clear an alarm"）。它会跳过回零：仅在激光头处于安全位置时使用 |
| `$$` | 打印设置 | **固件 ($$)**（**Firmware ($$)**）页面，以及连接后读取一次以检查激光模式（`$32`）和 `$30` |
| `$N=value` | 写入设置 | 同一页面，每次一个值，需确认 |
| `$J=...` | 点动（一种可以立即取消、且永远不会在作业运行时执行的运动） | 点动箭头，例如 `$J=G91 G21 X10 Y0 F3000` |
| `$G`、`$#`、`$I`、`$C`、`$N` | 解析器状态、坐标偏移、构建信息、检查模式、启动行 | 未使用 |

## 程序写入的 G-code

| 代码 | 含义 |
|---|---|
| `G21` | 毫米 |
| `G90` | 绝对坐标 |
| `G17` | XY 平面 |
| `G0 X.. Y..` | 快速移动（激光关闭） |
| `G1 X.. Y.. S.. F..` | 以功率 `S` 和进给 `F` 进行切割移动 |
| `G2` / `G3` | 顺时针 / 逆时针圆弧，在设备写入圆弧时使用 |
| `G91` | 相对坐标，仅在点动中使用 |

| 代码 | 含义 |
|---|---|
| `M3 S0` | 恒定功率：程序运行期间激光保持在 `S`（对焦光束、使用恒定功率的图层的作业） |
| `M4 S0` | 动态功率：功率跟随速度变化，因此转角不会烧得更深（需要 `$32=1`，激光模式） |
| `M5` | 激光关闭 |
| `M8` / `M9` | 辅助吹气开 / 关（或设备的自定义命令） |
| `M2` | 程序结束 |

`S` 的范围是 0 到激光头的 **S 值最大值**（**S-value max**）（`$30`）。如果你设置了设备的自定义开始行、钩子和宏，作业也会以它们开始。

## 设置（`$n`）

下面的列表就是固件页面所显示的列表；在那里将鼠标悬停在某一行上可查看说明。标记为 **关键**（**critical**）的值可能会使激光发射或使机器朝错误方向移动，因此页面在写入它们之前会要求确认。

| `$` | 名称 | 单位 |
|---|---|---|
| 0 | 步进脉冲时间 | µs |
| 1 | 步进空闲延时 | ms |
| 2 / 3 | 步进脉冲 / 方向反转 | 掩码 |
| 4, 5, 6 | 反转步进使能 / 限位引脚 / 探针引脚 | 0 / 1 |
| 10 | 状态报告选项 | 掩码 |
| 11 | 拐角偏差 | mm |
| 12 | 圆弧容差 | mm |
| 13 | 以英寸报告 | 0 / 1 |
| 20 | 软限位 | 0 / 1 |
| 21 | 硬限位 | 0 / 1 |
| 22 | 回零循环 | 0 / 1 |
| 23 | 回零方向反转 | 掩码 |
| 24 / 25 | 回零进给 / 寻找速度 | mm/min |
| 26 | 回零去抖 | ms |
| 27 | 回零退离距离 | mm |
| 30 | 主轴最大转速（100 % 对应的 S），**关键** | S |
| 31 | 主轴最小转速，**关键** | S |
| 32 | 激光模式，**关键** | 0 / 1 |
| 100–102 | X、Y、Z 每毫米步数 | steps/mm |
| 110–112 | X、Y、Z 最大速率 | mm/min |
| 120–122 | X、Y、Z 加速度 | mm/s² |
| 130–132 | X、Y、Z 最大行程，**关键** | mm |

对于激光器：`$32=1`（激光模式），且 `$30` 等于配置文件的 S 值最大值（大多数主板为 1000，部分为 255）。连接后，如果激光模式关闭或 `$30` 与配置文件不同，LightCreator 会发出警告。

## 状态报告中的状态

`<Idle|MPos:10.000,20.000,0.000|FS:0,0>`：第一个词是状态。

| 状态 | 含义 |
|---|---|
| `Idle` | 等待工作 |
| `Run` | 正在移动（作业、框选、点动） |
| `Hold:0` / `Hold:1` | 进给保持：0 = 已完全停止，1 = 仍在减速 |
| `Jog` | 点动运动 |
| `Home` | 正在回零 |
| `Alarm` | 已锁定：用 `$X` 解锁或回零 |
| `Door:0`–`Door:3` | 安全门状态 |
| `Check` | 检查模式（`$C`）：只检查移动 |
| `Sleep` | 休眠 |

## 应答

* `ok`：该行已被理解并放入规划器。LightCreator 会计算等待 `ok` 的各行的字节数，使控制器 128 字节的接收缓冲区保持满载但不溢出（或在 *简单*（*Simple*）流式传输中一次发送一行）。
* `error:N`：该行被拒绝。作业继续进行（该行视为已应答），控制台显示错误。
* `ALARM:N`：机器已停止并被锁定。
* `[MSG:...]`、`[GC:...]`、`Grbl 1.1h ['$' for help]`：信息，从不算作应答。复位后的欢迎信息告诉程序 GRBL 已就绪。

### `error:N`

| N | 含义 |
|---|---|
| 1 | G-code 字是一个不带数字的字母，或缺少字母 |
| 2 | 数字格式错误或缺少数字 |
| 3 | `$` 命令未知或不受支持 |
| 4 | 需要正值的地方出现了负值 |
| 5 | 未启用回零（`$22`） |
| 6 | 步进脉冲时间小于 3 µs |
| 7 | 读取 EEPROM 失败；已恢复默认值（刷写固件后通常会出现一次） |
| 8 | 该 `$` 命令仅在 GRBL 空闲时有效 |
| 9 | 报警或点动期间 G-code 被锁定 |
| 10 | 软限位需要启用回零 |
| 11 | 该行超过了 GRBL 接受的长度，已被丢弃 |
| 12 | 某项设置超过了 GRBL 支持的步进速率 |
| 13 | 安全门已打开 |
| 14 | 启动行或构建信息对于 EEPROM 来说太长 |
| 15 | 点动目标超出机器的行程 |
| 16 | 点动命令缺少 `=` 或包含禁止的 G-code |
| 17 | 激光模式需要 PWM 主轴输出 |
| 20 | 不支持或无效的 G-code 命令 |
| 21 | 一行中有同一模态组的两个命令 |
| 22 | 尚未设置进给速度 |
| 23 | 该命令需要整数值 |
| 24 | 一行中有两个都需要轴字的命令 |
| 25 | 该行中某个 G-code 字重复 |
| 26 | 该命令需要轴字，但没有轴字 |
| 27 | `N` 行号超出 1 – 9 999 999 的范围 |
| 28 | 缺少必需的 `P` 或 `L` 值 |
| 29 | 只有工作坐标系 G54–G59 存在（G59.1–G59.3 不存在） |
| 30 | G53 需要 G0 或 G1 运动模式 |
| 31 | 在运动模式取消（G80）生效时出现未使用的轴字 |
| 32 | 圆弧在所选平面中没有轴字 |
| 33 | 运动目标无效（不可能存在的圆弧） |
| 34 | 圆弧半径导致数学错误 |
| 35 | 使用偏移的圆弧缺少其平面的 I、J 或 K 字 |
| 36 | 存在没有任何命令使用的多余 G-code 字 |
| 37 | G43.1 只能偏移其配置的轴 |
| 38 | 刀具编号超过支持的最大值 |

### `ALARM:N`

| N | 含义 | 处理方法 |
|---|---|---|
| 1 | 硬限位被触发；位置可能已丢失 | 检查限位开关，重新回零 |
| 2 | G-code 目标超出行程（软限位）；位置被保留 | 使用 `$X` 即可；根据工作区检查作业 |
| 3 | 移动中复位；位置无法保证 | 重新回零 |
| 4 | 探测失败：探针不在初始状态 | 检查探针（LightCreator 不使用） |
| 5 | 探测失败：在行程内未接触 | 同上 |
| 6 | 回零失败：回零循环中发生复位 | 重新回零 |
| 7 | 回零失败：安全门被打开 | 关上安全门，重新回零 |
| 8 | 回零失败：退离时限位开关未释放 | 增大 `$27` 或检查接线 |
| 9 | 回零失败：未找到限位开关 | 检查限位开关、方向（`$23`）和接线 |

*解锁*（*Unlock*）按钮发送 `$X`。它不会移动机器：如果激光头在机器锁定期间被移动过，在你回零之前，程序中的位置将不再与实际情况相符。
