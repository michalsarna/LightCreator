# Skróty klawiszowe

| Plik | Ctrl+N / O / S | Nowy / otwórz / zapisz |
| | Ctrl+Shift+S | Zapisz jako |
| | Ctrl+I | Import SVG |
| Edycja | Ctrl+Z / Ctrl+Y | Cofnij / ponów |
| | Ctrl+C / V / D | Kopiuj / wklej / powiel |
| | Delete | Usuń |
| | Ctrl+A | Zaznacz wszystko |
| | Strzałki | Przesuń (Shift = 10×) |

| Widok | Ctrl+0 / Ctrl+9 | Dopasuj do pola roboczego / do wszystkich obiektów |

| | Spacja (przytrzymaj) | Przesuwanie widoku dowolnym narzędziem |
