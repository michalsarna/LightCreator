# Skróty klawiszowe

Na macOS **Ctrl** czytaj jako **Cmd**. Gdy piszesz w polu tekstowym, klawisze należą do tego pola (kopiuj, wklej, usuń, zaznacz wszystko i jednoliterowe klawisze narzędzi nie działają wtedy na rysunek). **Krótki przewodnik** (**F1**) pokazuje najważniejsze klawisze w programie. Każda pozycja menu z jej klawiszem jest na stronie [Menu](Menu).

**macOS:** **Ctrl+P**, **Ctrl+E** i **Ctrl+Shift+P** działają tylko z paskiem menu w oknie (Windows i Linux); na macOS użyj **Plik → Drukuj…**, **Laser → Eksportuj G-code…** i **Laser → Okno podglądu…**. **Cmd+Q** to **Zakończ** w menu LightCreator.

## Plik

| Skrót | Działanie |
|---|---|
| Ctrl+N | Nowy rysunek w nowej karcie |
| Ctrl+O | Otwórz projekt |
| Ctrl+S | Zapisz |
| Ctrl+Shift+S | Zapisz jako |
| Ctrl+I | Importuj SVG |
| Ctrl+P | Drukuj (Windows i Linux) |
| Ctrl+Q | Zakończ |

## Laser

| Skrót | Działanie |
|---|---|
| Ctrl+E | **Eksportuj G-code…** (Windows i Linux) |
| Ctrl+Shift+P | **Okno podglądu…** (Windows i Linux) |

## Edycja

| Skrót | Działanie |
|---|---|
| Ctrl+Z | Cofnij |
| Ctrl+Y lub Ctrl+Shift+Z | Ponów |
| Ctrl+C / Ctrl+V | Kopiuj / wklej |
| Ctrl+D | Powiel |
| Delete lub Backspace | Usuń zaznaczenie (w edycji węzłów: zaznaczone węzły) |
| Ctrl+A | Zaznacz wszystko |
| Strzałki | Przesuń zaznaczenie o 1 mm; **Shift** + strzałka = 10 mm |

## Rozmieszczenie

| Skrót | Działanie |
|---|---|
| Ctrl+G / Ctrl+Shift+G | Grupuj / rozgrupuj |
| Ctrl+L / Ctrl+Shift+L | Zablokuj / odblokuj |
| N | Edytuj węzły (narzędzie węzłów) |

## Narzędzia

Jeden klawisz, bez modyfikatora. Te same klawisze są w podpowiedziach paska narzędzi i w nazwach pozycji menu **Wstawianie**.

| Klawisz | Narzędzie | Klawisz | Narzędzie |
|---|---|---|---|
| V | Zaznaczanie | S | Gwiazda |
| N | Edycja węzłów | G | Wielokąt (małe okienko ustawia liczbę boków) |
| R | Prostokąt | K | Serce |
| E | Elipsa | I | Spirala (małe okienko ustawia liczbę zwojów) |
| Y | Trójkąt | L | Linia |
| P | Linia łamana / pióro | T | Tekst |
| H | Przesuwanie widoku | Z / X | Powiększ / pomniejsz |

## Karty otwartych rysunków

| Skrót | Działanie |
|---|---|
| Ctrl+1 … Ctrl+9, Ctrl+0 | Pokaż 1. … 9., 10. otwarty rysunek |
| Ctrl+W | Zamknij pokazany rysunek (pyta, gdy ma niezapisaną pracę; zamknięcie ostatniego zamyka program) |
| Ctrl+N | Nowy rysunek w nowej karcie |

## Widok

| Skrót | Działanie |
|---|---|
| Ctrl+Shift+0 | Dopasuj obszar roboczy do okna (i trzymaj go dopasowanym, dopóki nie zmienisz powiększenia ręcznie) |
| Ctrl+Shift+9 | Dopasuj do wszystkich obiektów |
| Ctrl++ (lub Ctrl+=) / Ctrl+- | Zbliżenie / oddalenie wokół środka widoku |
| Spacja (przytrzymaj) | Przesuwanie widoku dowolnym narzędziem; po puszczeniu wraca poprzednie narzędzie |
| Escape | Wyczyść zaznaczenie i niedokończoną łamaną (w edycji węzłów najpierw zaznaczone węzły) |
| Escape dwa razy | Powrót do narzędzia zaznaczania |
| F1 | Krótki przewodnik |

## Mysz i dotyk

| Gest | Działanie |
|---|---|
| Kółko | Zbliżenie wokół wskaźnika (także w podglądzie i w widoku z kamery) |
| Przeciąganie środkowym przyciskiem | Przesuwanie widoku |
| Szczypanie (touchpad) | Zbliżenie |
| Klik; **Shift**+klik lub **Ctrl**+klik | Zaznacz; dodaj do zaznaczenia lub odejmij od niego |
| Ramka przeciągnięta z lewej do prawej | Zaznacza to, co jest w całości w środku |
| Ramka przeciągnięta z prawej do lewej | Zaznacza wszystko, czego dotyka |
| **Shift** przy rysowaniu | Kwadrat, koło lub równe boki |
| Przeciąganie uchwytu narożnego | Zmiana rozmiaru z zachowaniem proporcji; z **Shift** dowolnie |
| **Shift** przy obracaniu | Kroki co 15° |
| **Shift** z narzędziem zbliżania | Odwrotnie: narzędzie powiększania oddala, narzędzie pomniejszania przybliża |
| Ponowny klik w uchwyt zaznaczenia | Przełącza między uchwytami skalowania a obrotu i pochylania |
| Dwuklik w kształt | Edycja jego węzłów (nie dla tekstu i obrazów) |
| Dwuklik w odcinek (edycja węzłów) | Dodaje węzeł |
| Narzędzie łamanej: klik w pierwszy punkt | Zamyka linię |
| Narzędzie łamanej: prawy przycisk, **Enter** lub dwuklik | Kończy linię |
| Prawy przycisk (inne narzędzia) | Menu podręczne z poleceniami rozmieszczenia (nie z narzędziami przesuwania i zbliżania) |
| Dwuklik w widoku z kamery | Powrót do całego obrazu |
| Przeciągnięcie karty | Przenosi ją w inne miejsce jej paska albo na inny panel |
| Prawy przycisk na karcie | **Przenieś na panel N** (Move to pane N), **Otwórz w osobnym oknie** (Open in a separate window; podgląd, tekst G-code, kamera), **Zamknij kartę** (Close tab) |
