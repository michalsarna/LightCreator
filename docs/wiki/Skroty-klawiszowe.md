# Skróty klawiszowe

Na macOS **Ctrl** czytaj jako **Cmd**. Skróty edytujące tekst (kopiuj, wklej, usuń, zaznacz wszystko) zostają przy polu tekstowym, gdy w nim piszesz. Przewodnik (**F1**) pokazuje te same klawisze w programie.

## Plik

| Skrót | Działanie |
|---|---|
| Ctrl+N | Nowy projekt |
| Ctrl+O | Otwórz projekt |
| Ctrl+S | Zapisz |
| Ctrl+Shift+S | Zapisz jako |
| Ctrl+I | Import SVG |
| Ctrl+P | Drukuj |
| Ctrl+Q | Zakończ (Windows i Linux; na macOS skrót należy do menu systemowego) |

## Edycja

| Skrót | Działanie |
|---|---|
| Ctrl+Z | Cofnij |
| Ctrl+Y lub Ctrl+Shift+Z | Ponów |
| Ctrl+C / Ctrl+V | Kopiuj / wklej |
| Ctrl+D | Powiel |
| Delete lub Backspace | Usuń zaznaczenie (w edycji węzłów: zaznaczone węzły) |
| Ctrl+A | Zaznacz wszystko |
| Strzałki | Przesuń zaznaczenie o 1 mm; **Shift** = 10 mm |

## Rozmieszczenie

| Skrót | Działanie |
|---|---|
| Ctrl+G / Ctrl+Shift+G | Grupuj / rozgrupuj |
| Ctrl+L / Ctrl+Shift+L | Zablokuj / odblokuj |

## Narzędzia

Jeden klawisz, bez modyfikatora. Te same klawisze są w podpowiedziach paska narzędzi.

| Klawisz | Narzędzie | Klawisz | Narzędzie |
|---|---|---|---|
| V | Zaznaczanie | S | Gwiazda |
| N | Edycja węzłów | G | Wielokąt (pyta o liczbę boków) |
| R | Prostokąt | K | Serce |
| E | Elipsa | I | Spirala (pyta o liczbę zwojów) |
| Y | Trójkąt | L | Linia |
| P | Łamana / pióro | T | Tekst |
| H | Przesuwanie widoku | Z / X | Powiększanie / pomniejszanie |

## Karty otwartych rysunków

| Skrót | Działanie |
|---|---|
| Ctrl+1 … Ctrl+9, Ctrl+0 | Pokaż 1. … 9., 10. kartę |
| Ctrl+W | Zamknij pokazaną kartę (pyta, gdy ma niezapisaną pracę; zamknięcie ostatniej karty zamyka program) |
| Ctrl+N | Nowy rysunek w nowej karcie |

## Widok

| Skrót | Działanie |
|---|---|
| Ctrl+Shift+0 | Dopasuj obszar roboczy do okna (i trzymaj go dopasowanym, dopóki nie zmienisz powiększenia ręcznie) |
| Ctrl+Shift+9 | Dopasuj do wszystkich obiektów |
| Ctrl++ / Ctrl+- | Zbliżenie / oddalenie wokół środka widoku |
| Spacja (przytrzymaj) | Przesuwanie widoku dowolnym narzędziem; po puszczeniu wraca poprzednie narzędzie |
| Escape | Wyczyść zaznaczenie i niedokończoną łamaną |
| Escape dwa razy | Powrót do narzędzia zaznaczania |
| F1 | Przewodnik |

## Mysz i dotyk

| Gest | Działanie |
|---|---|
| Kółko | Zbliżenie wokół wskaźnika (także w podglądzie i w widoku kamery) |
| Przeciąganie środkowym przyciskiem | Przesuwanie widoku |
| Szczypanie (touchpad) | Zbliżenie |
| Klik, **Shift**+klik | Zaznacz, dodaj do zaznaczenia lub odejmij |
| Ramka przeciągnięta z lewej do prawej | Zaznacza to, co jest w całości w środku |
| Ramka przeciągnięta z prawej do lewej | Zaznacza wszystko, czego dotyka |
| **Shift** przy rysowaniu | Kwadrat, koło lub równe boki |
| **Shift** przy obracaniu | Kroki co 15° |
| **Shift** z narzędziem zbliżania | Oddala zamiast przybliżać |
| Ponowny klik w uchwyt zaznaczenia | Przełącza między uchwytami skalowania a obrotu i pochylania |
| Dwuklik w kształt | Edycja jego węzłów (nie dla tekstu i obrazów) |
| Dwuklik w odcinek (edycja węzłów) | Dodaje węzeł |
| Prawy przycisk | Menu podręczne z poleceniami rozmieszczenia; z narzędziem łamanej kończy linię (tak samo **Enter** i dwuklik) |
| Dwuklik w widoku kamery | Powrót do całego obrazu |

## Na stronie WWW serwera

| Gest | Działanie |
|---|---|
| Dwuklik w podgląd projektu lub przycisk ⛶ | Pełny ekran |
| Kółko, szczypanie, przeciąganie | Zbliżanie i przesuwanie podglądu |
| Escape | Wyjście z pełnego ekranu |

Wiążąca jest lista w programie (F1); jeśli się różnią, rację ma program.
