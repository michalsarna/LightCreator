# 窗格与标签页

如何布置 LightCreator 的工作区：绘图与其预览并排、同时显示两个绘图、将预览放到第二台显示器上。这里的所有内容在 LightCreator、MillCreator 和 PenCreator 中都相同。

```
+--------------------------------------------+------------------+
| drawing A | drawing B | + || Preview | +    | Properties | ... |
|---------------------------||----------------|                  |
|                           ||                |   right panel    |
|          pane 1           ||     pane 2     |  (its own tabs)  |
|                           ||                |                  |
+--------------------------------------------+------------------+
```

## 什么是标签页

工作区以 **标签页**（**tabs**）的形式显示内容，标签栏位于工作区上方：

* 每个打开的 **绘图**（**drawing**）（标签页上的圆点表示有未保存的更改）；
* **预览**（**Preview**）；
* **预览 G-code**（**Preview G-code**）：项目的 G-code 文本；
* 某个文件的 **G-code 分析**（**G-code analysis**）；
* **摄像头视图**（**Camera view**），当它以标签页形式显示在工作区中时。

标签栏末尾的 **+** 会新建一个绘图。每个标签页只存在一个：打开一个已经打开的项目会显示其标签页，每个项目只有一个预览、一个 G-code 文本和一个摄像头视图。

**窗格**（**pane**）是工作区中拥有自己标签栏的一部分。**最多有三个窗格**。只有一个窗格时（初始状态），你只会看到一个标签栏。

## 创建第二个窗格

先打开至少 **两个标签页**：窗格需要有自己的标签页，因此只有一个标签页时什么也不会发生。然后可以：

* 使用 **视图 → 拆分视图：并排**（**View → Split view: side by side**）或 **视图 → 拆分视图：上下排列**（**View → Split view: one above the other**）：标签栏中的最后一个标签页会移到新窗格中；或者
* 右键单击要移动的标签页，然后选择 **移到窗格 2**（**Move to pane 2**）。

## 创建第三个窗格

在含有两个或更多标签页的窗格中右键单击一个标签页，然后选择 **移到窗格 3**（**Move to pane 3**）。**拆分视图**（**Split view**）菜单项只能创建第二个窗格。

## 移动标签页

* 将 **标签页拖到** 另一个窗格的标签栏上：一条线会显示它将落在的位置。或者将其放到该窗格的主体区域上（该窗格会显示一个边框）：标签页会移到其标签栏的末尾。
* 在其自身的标签栏内拖动可以改变顺序。
* 或者使用其菜单（右键单击）：**移到窗格 N**（**Move to pane N**）。

拖动只能在现有窗格之间移动标签页：新窗格需要通过菜单创建。

## 改变大小和方向

* **拖动两个窗格之间的分隔线** 可以改变它们的大小。窗格不会小于 160 点。
* **双击分隔线** 可使各窗格大小相等。
* 有两个或三个窗格时，**视图 → 拆分视图：…**（**View → Split view: …**）可以改变方向：并排或上下排列。标签页保持在原位。

## 回到一个窗格

* **视图 → 单一视图**（**View → Single view**）会将所有标签页重新放到一个窗格中。
* 关闭窗格中的最后一个标签页会关闭该窗格，其他窗格随之合拢。将其最后一个标签页移走也是如此。
* 关闭最后一个打开的绘图时（如有未保存的工作，会先询问是否保存），会询问 **关闭程序？**（**Close the program?**）：**关闭程序**（**Close the program**）会关闭程序，**返回启动界面**（**Back to the start screen**）（或按 Escape）会显示启动界面。

## 关闭标签页

单击其关闭按钮（叉号），用 **鼠标中键** 单击它，或在其菜单（右键单击）中选择 **关闭标签页**（**Close tab**）。有未保存更改的绘图会先进行询问。

## 工具作用于哪个绘图

有一个绘图是 **活动**（**active**）绘图：工具、菜单和快捷键都作用于它。另一个窗格中的绘图仅供查看，有自己的缩放比例。**单击它或它的标签页，即可使其成为活动绘图。**

## 在单独窗口中显示标签页

**预览**、**G-code 文本** 和 **摄像头视图** 可以移到单独的窗口中，例如放到第二台显示器上。绘图不能这样做。

1. 右键单击标签页，然后选择 **在单独窗口中打开**（**Open in a separate window**）。
2. 将窗口移到你想要的位置。它会记住自己的位置和大小。
3. 窗口顶部的 **返回主窗口**（**Back to the main window**），或关闭该窗口，会将标签页放回你上次使用的窗格中。

**视图 → 单一视图** 不会影响这些窗口。

## 三种工作方式

* **绘图和预览并排：**打开预览（**激光 → 预览窗口…**（**Laser → Preview window…**）或 **预览…**（**Preview…**）按钮；Ctrl+Shift+P），然后选择 **视图 → 拆分视图：并排**。检查移到窗格 2 的是否是预览标签页；如果不是，把它拖过去。
* **同时显示两个绘图：**打开两个绘图，然后选择 **视图 → 拆分视图：并排**。单击你要编辑的那个：另一个会以自己的缩放比例保持可见。
* **在第二台显示器上显示预览：**右键单击预览标签页，选择 **在单独窗口中打开**，然后将窗口拖到那台显示器上。

## 右侧面板

右侧的面板与窗格是分开的。它有自己的标签页：**属性**（**Properties**）、**图层**（**Layers**）、**设备**（**Device**）、**控制**（**Control**）、**控制台**（**Console**）、**剪贴画**（**Clipart**）、**描述**（**Description**）和 **录制**（**Recording**）（每个摄像头一个面板、移开拍照、长线），以及在需要时出现的摄像头或插件标签页（这两者始终位于该行的末尾）。

* 在其所在行中 **拖动标签页** 可以改变顺序。顺序会被记住。
* **拖动面板的左边缘** 可以改变其宽度。
* 该行开头的箭头会 **隐藏面板**：标签页的名称会竖排显示在一条窄条上。单击某个名称即可在该标签页上打开面板；窄条上的按钮（**显示面板**（**Show the panel**））会再次打开面板。

右侧面板的标签页与工作区的标签页不能混用：你不能把一个拖到另一个中。

## 会被记住的内容

窗格、其中的标签页、方向和大小都会随程序设置一起保存，并在你再次启动程序时恢复，已不再打开的内容的标签页除外。右侧面板标签页的顺序以及面板是否隐藏也会被记住。
