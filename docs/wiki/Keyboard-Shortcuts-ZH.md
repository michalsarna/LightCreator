# 键盘快捷键

在 macOS 上请将 **Ctrl** 理解为 **Cmd**。在文本框中输入时，按键归该文本框使用（复制、粘贴、删除、全选以及单字母工具键不会作用于绘图）。**快速指南**（**Quick guide**）（**F1**）在程序内列出了主要的快捷键。每个菜单项及其快捷键都列在 [菜单](Menus-ZH) 页面中。

**macOS：**下面的每个快捷键都可以配合 Cmd 使用，尽管系统菜单栏只在新建（New）、打开…（Open…）、保存（Save）、另存为…（Save as…）和导入 SVG…（Import SVG…）旁边显示快捷键。**Cmd+Q** 是 LightCreator 菜单中的 **退出**（**Quit**）。

## 文件

| 快捷键 | 操作 |
|---|---|
| Ctrl+N | 在新标签页中新建绘图 |
| Ctrl+O | 打开项目 |
| Ctrl+S | 保存 |
| Ctrl+Shift+S | 另存为 |
| Ctrl+I | 导入 SVG |
| Ctrl+P | 打印 |
| Ctrl+Q | 退出 |

## 激光

| 快捷键 | 操作 |
|---|---|
| Ctrl+E | **导出 G-code…**（**Export G-code…**） |
| Ctrl+Shift+P | **预览窗口…**（**Preview window…**） |

## 编辑

| 快捷键 | 操作 |
|---|---|
| Ctrl+Z | 撤销 |
| Ctrl+Y 或 Ctrl+Shift+Z | 重做 |
| Ctrl+C / Ctrl+V | 复制 / 粘贴 |
| Ctrl+D | 再制 |
| Delete 或 Backspace | 删除所选内容（在节点编辑中：删除所选节点） |
| Ctrl+A | 全选 |
| 方向键 | 将所选内容微移 1 mm；**Shift** + 方向键 = 10 mm（在控制（Control）标签页中开启 **键盘**（**Keyboard**）时不适用，见下文） |

## 排列

| 快捷键 | 操作 |
|---|---|
| Ctrl+G / Ctrl+Shift+G | 编组 / 取消编组 |
| Ctrl+L / Ctrl+Shift+L | 锁定 / 解锁 |
| N | 编辑节点（节点工具） |

## 工具

单个按键，不带修饰键。工具栏的提示和 **插入**（**Insert**）菜单的名称中也显示相同的按键。

| 按键 | 工具 | 按键 | 工具 |
|---|---|---|---|
| V | 选择 | S | 星形 |
| N | 节点编辑 | G | 多边形（一个小窗口用于设置边数） |
| R | 矩形 | K | 心形 |
| E | 椭圆 | I | 螺旋线（一个小窗口用于设置圈数） |
| Y | 三角形 | L | 直线 |
| P | 折线 / 钢笔 | T | 文字 |
| H | 平移 | Z / X | 放大 / 缩小 |

## 用键盘点动机器

在 **控制**（**Control**）标签页中开启 **键盘**（**Keyboard**）（默认关闭）后，按键会按该标签页中选择的步长移动机器，而不是移动所选形状。需要连接。

| 按键 | 操作 |
|---|---|
| 方向键 | 将 X 和 Y 点动一步 |
| Page Up / Page Down | 将 Z 点动一步（仅适用于有 Z 轴的机器） |

## 打开的绘图的标签页

| 快捷键 | 操作 |
|---|---|
| Ctrl+1 … Ctrl+9、Ctrl+0 | 显示第 1 … 9 个、第 10 个打开的绘图 |
| Ctrl+W | 关闭当前显示的绘图（有未保存的工作时会询问；关闭最后一个会关闭程序） |
| Ctrl+N | 在新标签页中新建绘图 |

## 视图

| 快捷键 | 操作 |
|---|---|
| Ctrl+Shift+0 | 使工作区适应窗口（并保持适应，直到你手动缩放） |
| Ctrl+Shift+9 | 显示全部对象 |
| Ctrl++（或 Ctrl+=）/ Ctrl+- | 以视图中心为基准放大 / 缩小 |
| Space（按住） | 在使用任何工具时平移；松开后回到原来的工具 |
| Escape | 清除所选内容和未完成的折线（在节点编辑中：先清除所选节点） |
| 按两次 Escape | 返回选择工具 |
| F1 | 快速指南 |

## 鼠标和触控

| 手势 | 操作 |
|---|---|
| 滚轮 | 以指针为中心缩放（在预览和摄像头视图中也适用） |
| 按住中键或右键拖动 | 平移（在工作区上及其旁边；不移动的右键单击会打开菜单） |
| 双指捏合（触控板） | 缩放 |
| 单击；**Shift**+单击或 **Ctrl**+单击 | 选择；添加到所选内容 / 从所选内容中移除 |
| 从左向右拖出选框 | 选中完全位于框内的内容 |
| 从右向左拖出选框 | 选中选框触及的所有内容 |
| 绘制时按住 **Shift** | 正方形、圆形或等边 |
| 拖动角控制柄 | 保持比例缩放；按住 **Shift** 时自由缩放 |
| 旋转时按住 **Shift** | 以 15° 为步进 |
| 使用缩放工具时按住 **Shift** | 反向操作：放大工具变为缩小，缩小工具变为放大 |
| 再次单击所选内容的控制柄 | 在缩放控制柄与旋转 / 倾斜控制柄之间切换 |
| 双击形状 | 编辑其节点（不适用于文字和图片） |
| 双击线段（节点编辑） | 添加节点 |
| 折线工具：单击第一个点 | 闭合该线 |
| 折线工具：右键单击、**Enter** 或双击 | 结束该线 |
| 右键单击（其他工具） | 带有排列命令的上下文菜单（平移和缩放工具除外） |
| 双击摄像头视图 | 恢复为完整画面 |
| 拖动标签页 | 将其移到所在标签栏中的其他位置或另一个窗格 |
| 右键单击标签页 | **移到窗格 N**（**Move to pane N**）、**在单独窗口中打开**（**Open in a separate window**）（预览、G-code 文本、摄像头）、**关闭标签页**（**Close tab**） |

## 在 Web 服务器的网页中

| 手势 | 操作 |
|---|---|
| 双击项目预览，或按 ⛶ 按钮 | 全屏 |
| 滚轮、双指捏合、拖动 | 缩放和移动预览 |
| Escape | 退出全屏 |
