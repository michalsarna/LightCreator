# 프로젝트 지원하기

LightCreator는 무료이며 오픈 소스입니다. 유용하게 쓰고 계신다면 작성자에게 커피 한 잔을 사 주실 수 있습니다: **<https://buymeacoffee.com/michalsarna>**

돈이 꼭 필요한 것은 아닙니다. 다음과 같은 방법으로도 도울 수 있습니다.
* [이슈](https://github.com/michalsarna/LightCreator/issues)에 버그와 아이디어 보고하기,
* 실제 기계(GRBL, Marlin, ser2net, 카메라)에서 테스트하고 결과 공유하기,
* 번역 개선하기,
* 클립아트 추가하기,
* 프로젝트에 별표를 주고 다른 사람에게 알리기.

감사합니다!
