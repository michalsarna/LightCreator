# Keyboard Shortcuts

| Group | Shortcut | Action |
|---|---|---|
| File | Ctrl+N / O / S | New / open / save |
| | Ctrl+Shift+S | Save as |
| | Ctrl+I | Import SVG |
| Edit | Ctrl+Z / Ctrl+Y | Undo / redo |
| | Ctrl+C / V / D | Copy / paste / duplicate |
| | Delete | Delete |
| | Ctrl+A | Select all |
| | Arrow keys | Nudge (Shift = 10×) |
| Arrange | Ctrl+G / Ctrl+Shift+G | Group / ungroup |
| | Ctrl+L / Ctrl+Shift+L | Lock / unlock |
| Tools | N | Node editing |
| | T | Text |
| | Y / S / G / K | Triangle / star / polygon / heart |
| | H / Z / X | Pan / zoom in / zoom out |
| View | Ctrl+0 / Ctrl+9 | Fit work area / fit all objects |
| | Ctrl++ / Ctrl+- | Zoom around the view centre |
| | Space (hold) | Pan with any tool |
| | Escape ×2 | Back to select tool |
| Help | F1 | Quick guide |

The Quick guide (F1) is the authoritative list.
