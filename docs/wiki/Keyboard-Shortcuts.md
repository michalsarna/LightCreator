# Keyboard Shortcuts

On macOS read **Ctrl** as **Cmd**. Shortcuts that edit text (copy, paste, delete, select all) stay with the text field while you type in one. The Quick guide (**F1**) lists the same keys inside the program.

## File

| Shortcut | Action |
|---|---|
| Ctrl+N | New project |
| Ctrl+O | Open a project |
| Ctrl+S | Save |
| Ctrl+Shift+S | Save as |
| Ctrl+I | Import SVG |
| Ctrl+P | Print |
| Ctrl+E | Export G-code (Laser menu) |
| Ctrl+Shift+P | Preview window (Laser menu) |
| Ctrl+Q | Quit (Windows and Linux; on macOS the system menu owns it) |

## Edit

| Shortcut | Action |
|---|---|
| Ctrl+Z | Undo |
| Ctrl+Y or Ctrl+Shift+Z | Redo |
| Ctrl+C / Ctrl+V | Copy / paste |
| Ctrl+D | Duplicate |
| Delete or Backspace | Delete the selection (in node editing: the selected nodes) |
| Ctrl+A | Select all |
| Arrow keys | Nudge the selection by 1 mm; **Shift** = 10 mm |

## Arrange

| Shortcut | Action |
|---|---|
| Ctrl+G / Ctrl+Shift+G | Group / ungroup |
| Ctrl+L / Ctrl+Shift+L | Lock / unlock |

## Tools

A single key, no modifier. The same keys are in the tooltips of the tool bar.

| Key | Tool | Key | Tool |
|---|---|---|---|
| V | Select | S | Star |
| N | Node edit | G | Polygon (asks for the number of sides) |
| R | Rectangle | K | Heart |
| E | Ellipse | I | Spiral (asks for the number of turns) |
| Y | Triangle | L | Line |
| P | Polyline / pen | T | Text |
| H | Pan | Z / X | Zoom in / zoom out |

## Tabs of open drawings

| Shortcut | Action |
|---|---|
| Ctrl+1 … Ctrl+9, Ctrl+0 | Show the 1st … 9th, the 10th tab |
| Ctrl+W | Close the shown tab (asks when it has unsaved work; closing the last tab closes the program) |
| Ctrl+N | A new drawing in a new tab |

## View

| Shortcut | Action |
|---|---|
| Ctrl+Shift+0 | Fit the work area to the window (and keep it fitted until you zoom by hand) |
| Ctrl+Shift+9 | Fit all objects |
| Ctrl++ / Ctrl+- | Zoom in / out around the centre of the view |
| Space (hold) | Pan with any tool; release it to go back to the tool you had |
| Escape | Clear the selection and the unfinished polyline |
| Escape twice | Back to the select tool |
| F1 | Quick guide |

## Mouse and touch

| Gesture | Action |
|---|---|
| Wheel | Zoom around the pointer (also in the preview and the camera view) |
| Middle button drag | Pan |
| Pinch (touchpad) | Zoom |
| Click, **Shift**+click | Select, add to / remove from the selection |
| Drag a frame left → right | Select what is wholly inside |
| Drag a frame right → left | Select everything the frame touches |
| **Shift** while drawing | Square, circle or equal sides |
| **Shift** while turning | Steps of 15° |
| **Shift** with the zoom tool | Zoom out instead of in |
| Click a handle of the selection again | Switch between resize and turn / slant handles |
| Double-click a shape | Edit its nodes (not for text and pictures) |
| Double-click a segment (node editing) | Add a node |
| Right-click | Context menu with the arrange commands; with the polyline tool it finishes the line (so do **Enter** and a double-click) |
| Double-click the camera view | Back to the whole picture |

## In the web page of the web server

| Gesture | Action |
|---|---|
| Double-click the project preview, or the ⛶ button | Full screen |
| Wheel, pinch, drag | Zoom and move the preview |
| Escape | Leave full screen |

The list in the program (F1) is authoritative; if the two differ, the program is right.
