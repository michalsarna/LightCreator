# Keyboard Shortcuts

On macOS read **Ctrl** as **Cmd**. While you type in a text field the keys belong to the field (copy, paste, delete, select all and the single-letter tool keys do not act on the drawing). The **Quick guide** (**F1**) lists the main keys inside the program. Every menu entry with its key is on [Menus](Menus).

**macOS:** every key below works with Cmd, although the system menu bar shows a key only beside New, Open…, Save, Save as… and Import SVG…. **Cmd+Q** is **Quit** in the LightCreator menu.

## File

| Shortcut | Action |
|---|---|
| Ctrl+N | New drawing in a new tab |
| Ctrl+O | Open a project |
| Ctrl+S | Save |
| Ctrl+Shift+S | Save as |
| Ctrl+I | Import SVG |
| Ctrl+P | Print |
| Ctrl+Q | Quit |

## Laser

| Shortcut | Action |
|---|---|
| Ctrl+E | **Export G-code…** |
| Ctrl+Shift+P | **Preview window…** |

## Edit

| Shortcut | Action |
|---|---|
| Ctrl+Z | Undo |
| Ctrl+Y or Ctrl+Shift+Z | Redo |
| Ctrl+C / Ctrl+V | Copy / paste |
| Ctrl+D | Duplicate |
| Delete or Backspace | Delete the selection (in node editing: the selected nodes) |
| Ctrl+A | Select all |
| Arrow keys | Nudge the selection by 1 mm; **Shift** + arrow = 10 mm (not while **Keyboard** is on in the Control tab, see below) |

## Arrange

| Shortcut | Action |
|---|---|
| Ctrl+G / Ctrl+Shift+G | Group / ungroup |
| Ctrl+L / Ctrl+Shift+L | Lock / unlock |
| N | Edit nodes (the node tool) |

## Tools

A single key, no modifier. The same keys are in the tooltips of the tool bar and in the names of the **Insert** menu.

| Key | Tool | Key | Tool |
|---|---|---|---|
| V | Select | S | Star |
| N | Node edit | G | Polygon (a small window sets the number of sides) |
| R | Rectangle | K | Heart |
| E | Ellipse | I | Spiral (a small window sets the number of turns) |
| Y | Triangle | L | Line |
| P | Polyline / pen | T | Text |
| H | Pan | Z / X | Zoom in / zoom out |

## Jogging the machine with the keyboard

With **Keyboard** switched on in the **Control** tab (off by default) the keys move the machine instead of the selected shapes, by the step chosen in the tab. It needs a connection.

| Key | Action |
|---|---|
| Arrow keys | Jog X and Y by one step |
| Page Up / Page Down | Jog Z by one step (only on a machine with a Z axis) |

## Tabs of open drawings

| Shortcut | Action |
|---|---|
| Ctrl+1 … Ctrl+9, Ctrl+0 | Show the 1st … 9th, the 10th open drawing |
| Ctrl+W | Close the drawing that is shown (asks when it has unsaved work; closing the last one closes the program) |
| Ctrl+N | A new drawing in a new tab |

## View

| Shortcut | Action |
|---|---|
| Ctrl+Shift+0 | Fit the work area to the window (and keep it fitted until you zoom by hand) |
| Ctrl+Shift+9 | Fit all objects |
| Ctrl++ (or Ctrl+=) / Ctrl+- | Zoom in / out around the centre of the view |
| Space (hold) | Pan with any tool; release it to go back to the tool you had |
| Escape | Clear the selection and the unfinished polyline (in node editing: first the selected nodes) |
| Escape twice | Back to the select tool |
| F1 | Quick guide |

## Mouse and touch

| Gesture | Action |
|---|---|
| Wheel | Zoom around the pointer (also in the preview and the camera view) |
| Middle button drag | Pan |
| Pinch (touchpad) | Zoom |
| Click; **Shift**+click or **Ctrl**+click | Select; add to / remove from the selection |
| Drag a frame left → right | Select what is wholly inside |
| Drag a frame right → left | Select everything the frame touches |
| **Shift** while drawing | Square, circle or equal sides |
| Drag a corner handle | Resize keeping the proportions; with **Shift** freely |
| **Shift** while turning | Steps of 15° |
| **Shift** with a zoom tool | The other way: the zoom-in tool zooms out, the zoom-out tool zooms in |
| Click a handle of the selection again | Switch between resize and turn / slant handles |
| Double-click a shape | Edit its nodes (not for text and pictures) |
| Double-click a segment (node editing) | Add a node |
| Polyline tool: click the first point | Close the line |
| Polyline tool: right-click, **Enter** or a double-click | Finish the line |
| Right-click (other tools) | Context menu with the arrange commands (not with the pan and zoom tools) |
| Double-click the camera view | Back to the whole picture |
| Drag a tab | Move it to another place in its bar or to another pane |
| Right-click a tab | **Move to pane N**, **Open in a separate window** (preview, G-code text, camera), **Close tab** |

## In the web page of the web server

| Gesture | Action |
|---|---|
| Double-click the project preview, or the ⛶ button | Full screen |
| Wheel, pinch, drag | Zoom and move the preview |
| Escape | Leave full screen |
