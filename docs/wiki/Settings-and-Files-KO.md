# 설정과 파일

언어, 색 구성표, 장치 프로필, 마지막으로 사용한 프로필, 창 크기는 하나의 파일 `app.ron`에 저장됩니다.

| 시스템 | 위치 |
|---|---|
| macOS | `~/Library/Application Support/baseCreator/apps/lightcreator/app.ron` |
| Windows | `%APPDATA%\baseCreator\apps\lightcreator\app.ron` |
| Linux | `$XDG_DATA_HOME/baseCreator/apps/lightcreator/app.ron`, 기본값은 `~/.local/share/baseCreator/apps/lightcreator/app.ron` |

* **공유 폴더.** LightCreator, MillCreator, PenCreator는 데이터를 하나의 폴더 `baseCreator`에 보관합니다(표는 그 안에 있는 프로그램 자체 설정의 위치를 보여 줍니다). **클립아트 갤러리는 공유됩니다**: 한 프로그램에서 저장하거나 다운로드한 그림이 다른 프로그램에도 나타납니다(`apps` 옆의 `clipart` 폴더, 이름, 범주, 출처, 라이선스, 작성자를 기록한 `index.json` 포함). 각 프로그램은 자체 설정, 장치 프로필, 재료, 공구를 `apps/<program>/app.ron`에 보관합니다. 다른 폴더를 사용하려면 환경 변수 `BASECREATOR_DIR`을 설정하십시오.
* 파일은 애플리케이션이 닫힐 때 기록됩니다. **모든 것을 초기화하려면 이 파일을 삭제하십시오.** 그러면 시작 창이 다시 장치 프로필을 묻습니다.
* 프로젝트(`.cre`), SVG, G-code는 원하는 곳에 저장됩니다. `.cre` 파일은 MillCreator 및 baseCreator 기반의 다른 프로그램과 공유됩니다. 이 파일에는 도면, 설명, 그리고 프로그램마다 하나의 섹션이 들어 있습니다. LightCreator는 자체 `laser` 섹션(프로젝트를 만든 기계의 이름과 작업 영역 X/Y/Z, 레이어가 포함된 선택한 재료, 레이어 순서)을 기록하고, 저장할 때 다른 프로그램의 섹션은 건드리지 않습니다. 컨트롤러, 연결, 포트, 카메라 또는 기타 장치 설정은 절대 기록하지 않습니다. 작업 영역이 다른 기계용으로 만든 프로젝트를 열면 경고가 표시되며, 선택한 장치는 계속 사용됩니다. **파일 → 최근 파일 열기**(File → Open recent)는 마지막으로 열거나 저장한 프로젝트와 SVG 파일 10개를 나열합니다(역시 `app.ron`에 보관; **목록 지우기**(Clear list)로 비움; 시작 창에는 처음 5개가 표시됨). 프로젝트 파일에는 **설명**(Description) 탭의 메모(G-code에 `; Note:` 주석으로 기록됨)와 카메라 오버레이의 오버레이 그림도 보관됩니다.
* 직접 저장하면 **파일이 저장되었습니다**(File saved) 메시지가 5초 동안 표시됩니다. **설정 → 프로그램 옵션…**(Settings → Program options…)에서 **자동 저장**(auto-save)을 설정합니다(기본값 120초마다). 파일 이름이 없는 작업은 임시 폴더에 기록되고, 이름이 있는 파일은 그 자리에 저장됩니다. 열려 있는 모든 도면에는 작업 영역 위에 **탭**이 있습니다(**파일 → 새로 만들기**(File → New), **열기…**(Open…), 바의 **+**로 최대 10개까지 만듦; 점은 저장하지 않은 작업이 있는 탭을 표시; Ctrl+1 … Ctrl+0으로 표시하고 Ctrl+W로 닫음). 작업 영역은 최대 세 개의 탭 창 영역으로 나눌 수 있습니다. [디자인 도구](Design-Tools-KO#보기와-탐색)를 참고하십시오. 저장하지 않은 작업이 있는 상태에서 프로그램을 닫으면 탭마다 **저장**(Save), **버리기**(Discard) (임시 파일을 삭제하고 종료), **취소**(Cancel) (프로그램으로 돌아감)를 묻습니다.
* **도움말 → 백업 다운로드…**(Help → Download backup…)는 설정(`app.ron`, 현재 상태 그대로)과 공유 `clipart` 갤러리 전체를 README와 함께 담은 zip을 어디에 저장할지 묻습니다. **도움말 → 백업에서 복원…**(Help → Restore from backup…)은 그런 파일을 다시 읽습니다(설정은 확인 후 대체되고, 그림은 갤러리에 **추가**되므로 그 사이에 MillCreator나 PenCreator가 저장한 것은 잃지 않습니다. MillCreator와 PenCreator에도 같은 두 항목이 있으며 다른 프로그램이 만든 백업은 거부합니다). 시작할 때 프로필 파일이 없으면 시작 창이 녹색 버튼으로 복원을 제안합니다. 레이어 프리셋도 zip에 들어 있습니다. 복원하면 현재 목록을 대체하며, 프리셋이 없는 오래된 백업은 목록을 그대로 둡니다. 제어 장치도 zip에 들어 있습니다. 복원하면 세 프로그램 모두에서 현재 제어 장치를 대체합니다.
* **도움말 → 진단 정보 내보내기 (zip)…**(Help → Export diagnostics (zip)…)는 버그 보고서에 첨부할 zip을 어디에 저장할지 묻습니다: `info.txt` (버전, 시스템, 장치, 연결), `device.json` (주소의 비밀번호를 가린 장치), `settings.txt` (웹 서버 키와 최근 파일 제외), `console.txt` (기계와의 연결을 오간 내용, 상태 폴링 제외), `project.cre` (열린 프로젝트). 보내기 전에 살펴보십시오. 디자인이 들어 있습니다.
* **업데이트:** 프로그램은 시작할 때 GitHub에서 새 릴리스를 찾습니다(**설정 → 프로그램 옵션…**에서 끌 수 있음). **도움말 → 업데이트 확인…**(Help → Check for updates…)은 이를 수동으로 수행하며, 새 버전이 있으면 패키지 페이지를 엽니다.
* 창에는 **자체적인 평평하고 각진 테두리**가 있습니다: 아이콘, 제목, 열린 파일이 표시되는 제목 표시줄과 최소화 / 최대화 / 닫기 버튼. 바를 드래그하면 창이 이동하고, 더블 클릭하면 최대화되며, 가장자리에서 크기를 조절합니다(macOS에서는 오른쪽과 아래쪽 가장자리).
* **설정**(Settings) 메뉴: **보기 옵션…**(View options…) (격자, 작업 영역의 배경, 그 주변 작업 공간의 색, 선 두께, 레이어 이름, 변수 이름, 저장 후 G-code 미리 보기), **프로그램 옵션…**(Program options…) (자동 저장, 업데이트 확인, 웹 서버와 API), **플러그인…**(Plugins…), **언어**(Language) (기본값 English), **색 구성표**(Colour scheme) (Dark, Light Dark, Medium Light, Light, 그리고 파란색, 녹색, 보라색, 갈색, 주황색의 어두운 구성표와 밝은 구성표; 기본값 Light Dark; 크리스마스, 새해 전날, 핼러윈, 부활절, 춘절 무렵에는 그 명절을 위한 어두운 축제 구성표와 밝은 축제 구성표가 추가됨). [메뉴](Menus-KO#설정-settings)를 참고하십시오.
* 인터페이스 언어(38개): English, Polski, Deutsch, Italiano, Suomi, 简体中文, हिन्दी; 日本語, 한국어, 繁體中文, Türkçe, Tiếng Việt, Bahasa Indonesia, Српски, Bosanski; 그리고 23개의 유럽 언어: Български, Català, Hrvatski, Čeština, Dansk, Nederlands, Eesti, Français, Ελληνικά, Magyar, Íslenska, Gaeilge, Latviešu, Lietuvių, Malti, Norsk bokmål, Português, Română, Slovenčina, Slovenščina, Español, Svenska, Українська. 유럽 언어 텍스트는 `assets/lang/`에 있으며(언어마다 파일 하나) 기계 번역의 도움을 받아 준비했으므로, 원어민의 수정을 환영합니다. 아이콘은 SVG 파일이고 글꼴(Noto Sans, Mono, SC, KR, Devanagari)은 `assets/`에서 내장되므로 모든 시스템에서 모양이 똑같습니다.

## 상태 표시줄과 버튼 색

아래쪽의 상태 표시줄은 장치의 상태(점과 함께: 연결되면 녹색)와 웹 서버의 상태(꺼짐, 포트와 함께 켜짐, 또는 오류)를 보여 줍니다. 저장 버튼은 **녹색**, 가져오기 버튼은 **파란색**, 삭제 버튼은 휴지통이 있는 **빨간색**입니다.

## 인쇄
**파일 → 인쇄…**(File → Print…) (Ctrl+P)는 디자인을 종이 프린터로 인쇄합니다. 페이지는 LightCreator가 만든 한 페이지짜리 PDF입니다: 전체 작업 영역을 실제 비율로(점선 테두리) 또는 객체만 페이지가 허용하는 만큼 크게; 표시된 레이어의 객체만 또는 전부; A4 또는 Letter; 0–40 mm의 여백. 인쇄되는 부분이 높이보다 너비가 크면 페이지가 가로 방향으로 바뀌며, 아래쪽 줄에 배율이 표시됩니다. 레이어는 각자의 색으로 그려지고, 채워진 도형은 옅게 색이 입혀지며, 이미지는 회색으로 그려집니다. 객체가 작업 영역 밖으로 나가면 경고가 표시됩니다(작업 영역 옵션에서는 가장자리에서 잘림).

**인쇄**(Print)는 페이지를 시스템 프린터로 보냅니다: macOS와 Linux에서는 `lp` (시스템이 나열하는 프린터 중 선택 가능), Windows에서는 기본 PDF 뷰어의 *인쇄*(Print) 동작(기본 프린터). **PDF로 저장…**(Save as PDF…)과 **PDF 열기**(Open the PDF) (더 많은 옵션으로 뷰어에서 인쇄)가 대안입니다. 인쇄 미리 보기는 PDF 자체입니다. 여기에 있는 기능은 아직 실제 프린터에서 시험하지 않았습니다.

## 비밀번호 보호

> ⚠️ 이 절은 영어판을 기계 번역한 것입니다.

프로젝트는 비밀번호로 보호할 수 있습니다: LightCreator, MillCreator, PenCreator의 **프로젝트 설정…**(**Project setup…**)과 BaseCreator의 **파일 → 페이지 설정…**(**File → Page setup…**)에 있는 **보호**(**Protection**) 부분에서 설정합니다.

* **소유자 비밀번호**: 모든 것(편집, 복사, 내보내기, 보호 변경 또는 해제).
* **열기 비밀번호**(선택): 프로젝트를 열고, 보고, G-code로 만들고, 기계에서 실행할 수 있으며, 재료와 레이어 설정(속도, 출력, 패스, 깊이, 비트, 펜)을 바꿀 수 있지만, 도면을 편집하거나 복사하거나 도면 형식(SVG, DXF, Illustrator, LightBurn …)으로 내보내거나 인쇄할 수는 없습니다. 이때 내장 웹 페이지는 도면을 보여 주지 않습니다.
* 소유자 비밀번호만 있으면 다른 사람은 파일을 열 수 없습니다. 비밀번호 없이는 파일을 전혀 읽을 수 없고, **잊은 비밀번호는 되찾을 수 없습니다**.
* 열기 비밀번호로 연 프로젝트는 다시 열지 않고 소유자 비밀번호로 잠금 해제할 수 있습니다: 설정의 **보호** 부분(**소유자 비밀번호**, **잠금 해제**)이나 탭 메뉴(오른쪽 클릭)의 **소유자 비밀번호로 잠금 해제…**에서 합니다. 이 메뉴에는 **프로젝트 정보…**와 프로젝트 설정도 있습니다.

파일은 `protected_cre` 키를 가진 JSON 텍스트로 남습니다. 그 안의 프로젝트는 무작위 256비트 키로 **XChaCha20-Poly1305** 암호화되며, 이 키는 비밀번호마다 한 번씩, **Argon2id**(64 MiB, 3회, 개별 솔트)로 비밀번호에서 만든 키로 감싸져 저장됩니다. 저장할 때마다 새 nonce를 쓰며, 바뀐 파일은 열리지 않습니다. 비밀번호는 8자 이상이어야 하고, 열기 비밀번호는 소유자 비밀번호와 달라야 합니다.

열기 비밀번호가 금지하는 것은 PDF의 소유자 비밀번호처럼 프로그램이 지킵니다: 그것을 아는 사람은 원칙적으로 다른 도구로 프로젝트를 해독할 수 있습니다. 소유자 비밀번호는 자신만 가지고 있으세요.
