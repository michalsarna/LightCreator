# GRBL 코드

LightCreator가 GRBL 컨트롤러로 보내는 내용과 컨트롤러가 응답하는 내용입니다. GRBL에 관한 사실은 **GRBL 1.1** (대부분의 다이오드 레이저가 사용하는 펌웨어) 기준이며, 다른 버전과 포크(grblHAL, FluidNC, 제조사 빌드)는 다를 수 있습니다. Sculpfun S9에서만 테스트했으며, 프로그램 자체의 스트리밍은 [GRBL 시뮬레이터](GRBL-Simulator-KO)로 테스트했습니다.

## 실시간 문자

작업 도중에도 GRBL이 즉시 처리하는 단일 바이트입니다. 줄이 아니므로 `ok`를 받지 않습니다.

| 바이트 | 의미 | LightCreator에서의 사용 |
|---|---|---|
| `?` | 상태 보고 | 초당 네 번 요청하며, 응답으로 상태와 위치를 채움 |
| `!` | 이송 일시 정지(feed hold) | **일시 정지**(Pause) |
| `~` | 사이클 시작 / 재개 | **재개**(Resume) |
| Ctrl+X (0x18) | 소프트 리셋 | **STOP**, 그리고 컨트롤러를 알려진 상태로 만들기 위해 연결 후 한 번 |

움직이는 중에 소프트 리셋을 하면 실제 GRBL 1.1은 `ALARM:3`을 발생시키며(위치를 잃음) `$X` 또는 원점 복귀가 필요합니다.

## 시스템 명령 (`$`)

| 명령 | 의미 | LightCreator에서의 사용 |
|---|---|---|
| `$H` | 원점 복귀 사이클 실행 | **원점 복귀**(Home), 연결 후 "기계 원점 복귀"(Home the machine), 정지 상태에서 **실시간 레이저 위치**(Live laser Position)를 켤 때 |
| `$HX`, `$HY` | 한 축만 원점 복귀(펌웨어가 보고할 때만) | *X 원점 복귀*(Home X) / *Y 원점 복귀*(Home Y) 버튼 |
| `$X` | 알람 잠금 해제 | **잠금 해제**(Unlock), 연결 후 "알람 해제"(Clear an alarm). 원점 복귀를 건너뛰므로 헤드가 안전한 곳에 있을 때만 사용하십시오 |
| `$$` | 설정 출력 | **펌웨어 ($$)**(Firmware ($$)) 페이지, 그리고 연결 후 레이저 모드(`$32`)와 `$30`을 확인하기 위해 한 번 |
| `$N=value` | 설정 기록 | 같은 페이지에서 확인 후 한 번에 한 값씩 |
| `$J=...` | 조그(즉시 취소할 수 있고 작업 중에는 절대 실행되지 않는 이동) | 조그 화살표, 예: `$J=G91 G21 X10 Y0 F3000` |
| `$G`, `$#`, `$I`, `$C`, `$N` | 파서 상태, 좌표 오프셋, 빌드 정보, 검사 모드, 시작 줄 | 사용하지 않음 |

## 프로그램이 작성하는 G-code

| 코드 | 의미 |
|---|---|
| `G21` | 밀리미터 |
| `G90` | 절대 좌표 |
| `G17` | XY 평면 |
| `G0 X.. Y..` | 급속 이동(레이저 꺼짐) |
| `G1 X.. Y.. S.. F..` | 출력 `S`와 이송 속도 `F`로 절단 이동 |
| `G2` / `G3` | 시계 방향 / 반시계 방향 호, 장치가 호를 작성할 때 |
| `G91` | 상대 좌표, 조그 안에서만 |

| 코드 | 의미 |
|---|---|
| `M3 S0` | 일정 출력: 프로그램이 실행되는 동안 레이저가 `S`로 유지됨(초점 빔, 일정 출력 레이어의 작업) |
| `M4 S0` | 동적 출력: 출력이 속도를 따르므로 모서리가 더 깊게 타지 않음(`$32=1`, 레이저 모드 필요) |
| `M5` | 레이저 끄기 |
| `M8` / `M9` | 에어 어시스트 켜기 / 끄기(또는 장치의 사용자 명령) |
| `M2` | 프로그램 끝 |

`S`는 0부터 헤드의 **S값 최대**(S-value max) (`$30`)까지입니다. 작업은 장치의 사용자 시작 줄, 훅, 매크로를 지정했다면 그것으로도 시작합니다.

## 설정 (`$n`)

아래 목록은 펌웨어 페이지에 표시되는 목록이며, 그 페이지에서 행에 마우스를 올리면 설명이 나옵니다. **중요**(critical)로 표시된 값은 레이저를 발사하거나 기계를 잘못된 방향으로 움직일 수 있으므로, 페이지가 기록하기 전에 확인을 요청합니다.

| `$` | 이름 | 단위 |
|---|---|---|
| 0 | 스텝 펄스 시간 | µs |
| 1 | 스텝 유휴 지연 | ms |
| 2 / 3 | 스텝 펄스 / 방향 반전 | 마스크 |
| 4, 5, 6 | 스텝 활성화 / 리밋 핀 / 프로브 핀 반전 | 0 / 1 |
| 10 | 상태 보고 옵션 | 마스크 |
| 11 | 접합 편차(junction deviation) | mm |
| 12 | 호 허용 오차 | mm |
| 13 | 인치로 보고 | 0 / 1 |
| 20 | 소프트 리밋 | 0 / 1 |
| 21 | 하드 리밋 | 0 / 1 |
| 22 | 원점 복귀 사이클 | 0 / 1 |
| 23 | 원점 복귀 방향 반전 | 마스크 |
| 24 / 25 | 원점 복귀 이송 / 탐색 속도 | mm/min |
| 26 | 원점 복귀 디바운스 | ms |
| 27 | 원점 복귀 후퇴 거리 | mm |
| 30 | 최대 스핀들 속도(100 %에 해당하는 S), **중요** | S |
| 31 | 최소 스핀들 속도, **중요** | S |
| 32 | 레이저 모드, **중요** | 0 / 1 |
| 100–102 | X, Y, Z mm당 스텝 수 | steps/mm |
| 110–112 | X, Y, Z 최대 속도 | mm/min |
| 120–122 | X, Y, Z 가속도 | mm/s² |
| 130–132 | X, Y, Z 최대 이동 거리, **중요** | mm |

레이저의 경우: `$32=1` (레이저 모드)이고 `$30`은 프로필의 S값 최대와 같아야 합니다(대부분의 보드에서 1000, 일부에서 255). LightCreator는 연결 후 레이저 모드가 꺼져 있거나 `$30`이 프로필과 다르면 경고합니다.

## 상태 보고의 상태

`<Idle|MPos:10.000,20.000,0.000|FS:0,0>`: 첫 번째 단어가 상태입니다.

| 상태 | 의미 |
|---|---|
| `Idle` | 작업 대기 중 |
| `Run` | 이동 중(작업, 프레임, 조그) |
| `Hold:0` / `Hold:1` | 이송 일시 정지: 0 = 정지 완료, 1 = 아직 감속 중 |
| `Jog` | 조그 이동 |
| `Home` | 원점 복귀 중 |
| `Alarm` | 잠김: `$X`로 잠금 해제하거나 원점 복귀 |
| `Door:0`–`Door:3` | 안전 도어 상태 |
| `Check` | 검사 모드(`$C`): 이동을 검사만 함 |
| `Sleep` | 절전 중 |

## 응답

* `ok`: 줄을 이해하고 플래너에 넣었습니다. LightCreator는 `ok`를 기다리는 줄의 바이트를 세어 컨트롤러의 128바이트 수신 버퍼를 넘치지 않게 가득 채웁니다(또는 *단순*(Simple) 스트리밍에서는 한 번에 한 줄씩 보냅니다).
* `error:N`: 줄이 거부되었습니다. 작업은 계속되며(그 줄은 응답을 받은 것으로 셈) 콘솔에 오류가 표시됩니다.
* `ALARM:N`: 기계가 멈추고 잠겼습니다.
* `[MSG:...]`, `[GC:...]`, `Grbl 1.1h ['$' for help]`: 정보이며, 응답으로 세지 않습니다. 리셋 후의 배너는 GRBL이 준비되었음을 프로그램에 알립니다.

### `error:N`

| N | 의미 |
|---|---|
| 1 | G-code 워드가 숫자 없는 문자이거나 문자가 없음 |
| 2 | 숫자의 형식이 잘못되었거나 숫자가 없음 |
| 3 | `$` 명령을 알 수 없거나 지원하지 않음 |
| 4 | 양수가 필요한 곳에 음수 값 |
| 5 | 원점 복귀가 활성화되지 않음(`$22`) |
| 6 | 스텝 펄스 시간이 3 µs 미만 |
| 7 | EEPROM 읽기 실패; 기본값이 복원됨(플래싱 후 한 번 자주 나타남) |
| 8 | `$` 명령은 GRBL이 유휴 상태일 때만 동작 |
| 9 | 알람이나 조그 중에는 G-code가 잠김 |
| 10 | 소프트 리밋에는 원점 복귀 활성화가 필요 |
| 11 | 줄이 GRBL이 받아들이는 길이보다 길어 버려짐 |
| 12 | 설정이 GRBL이 지원하는 스텝 속도를 초과 |
| 13 | 안전 도어가 열려 있음 |
| 14 | 시작 줄이나 빌드 정보가 EEPROM에 비해 너무 김 |
| 15 | 조그 목표가 기계의 이동 범위를 벗어남 |
| 16 | `=`가 없거나 금지된 G-code가 있는 조그 명령 |
| 17 | 레이저 모드에는 PWM 스핀들 출력이 필요 |
| 20 | 지원하지 않거나 잘못된 G-code 명령 |
| 21 | 한 줄에 같은 모달 그룹의 명령이 두 개 |
| 22 | 아직 이송 속도가 설정되지 않음 |
| 23 | 명령에 정수 값이 필요 |
| 24 | 한 줄에 축 워드가 필요한 명령이 두 개 |
| 25 | 줄에서 G-code 워드가 반복됨 |
| 26 | 명령에 축 워드가 필요한데 없음 |
| 27 | `N` 줄 번호가 1 – 9 999 999 범위를 벗어남 |
| 28 | 필수 `P` 또는 `L` 값이 없음 |
| 29 | 작업 좌표계는 G54–G59만 존재(G59.1–G59.3은 없음) |
| 30 | G53에는 G0 또는 G1 이동 모드가 필요 |
| 31 | 이동 모드 취소(G80)가 활성화된 상태에서 사용되지 않는 축 워드 |
| 32 | 선택한 평면에 축 워드가 없는 호 |
| 33 | 이동 목표가 잘못됨(존재할 수 없는 호) |
| 34 | 호 반지름에서 수학적 오류 발생 |
| 35 | 오프셋을 쓰는 호에 그 평면의 I, J 또는 K 워드가 없음 |
| 36 | 어떤 명령도 사용하지 않는 남은 G-code 워드 |
| 37 | G43.1은 구성된 축만 오프셋할 수 있음 |
| 38 | 공구 번호가 지원되는 최대값보다 큼 |

### `ALARM:N`

| N | 의미 | 조치 |
|---|---|---|
| 1 | 하드 리밋이 작동함; 위치를 잃었을 가능성이 높음 | 스위치를 확인하고 다시 원점 복귀 |
| 2 | G-code 목표가 이동 범위를 넘음(소프트 리밋); 위치는 유지됨 | `$X`로 충분함; 작업물을 작업 영역과 대조해 확인 |
| 3 | 이동 중 리셋; 위치가 보장되지 않음 | 다시 원점 복귀 |
| 4 | 프로브 실패: 시작 상태가 아님 | 프로브 확인(LightCreator에서는 사용하지 않음) |
| 5 | 프로브 실패: 이동 범위 안에서 접촉 없음 | 위와 같음 |
| 6 | 원점 복귀 실패: 사이클 중 리셋 | 다시 원점 복귀 |
| 7 | 원점 복귀 실패: 안전 도어가 열림 | 도어를 닫고 다시 원점 복귀 |
| 8 | 원점 복귀 실패: 후퇴 시 스위치가 해제되지 않음 | `$27`을 늘리거나 배선 확인 |
| 9 | 원점 복귀 실패: 스위치를 찾지 못함 | 스위치, 방향(`$23`), 배선 확인 |

*잠금 해제*(Unlock) 버튼은 `$X`를 보냅니다. 기계를 움직이지는 않습니다. 기계가 잠겨 있는 동안 헤드가 움직였다면, 원점 복귀를 할 때까지 프로그램의 위치는 실제와 맞지 않습니다.
