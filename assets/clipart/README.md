# Clipart shipped with LightCreator

310 single-colour silhouettes in 9 categories (one folder per category, one SVG per picture), taken from the
[Material Design Icons](https://pictogrammers.com/library/mdi/) collection by Pictogrammers
(<https://github.com/Templarian/MaterialDesign-SVG>), distributed under the **Apache License 2.0**
(`LICENSE-apache-2.0.txt`). The files are unchanged copies. Attribution: © Pictogrammers and contributors.

They are embedded in the program at build time (`crates/lightcreator/build.rs`). To add more pictures, drop SVG
files into a category folder here and rebuild; files that are not under a licence that allows redistribution
must not be added.
