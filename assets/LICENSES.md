# Third-party assets

Everything the interface shows comes from this folder: the fonts are embedded in the program (`crates/lightcreator/src/fonts.rs`,
`crates/lc-core/src/text.rs`) and the icons are embedded SVG files (`crates/lightcreator/src/icons.rs`).

| Path | Source | License |
|------|--------|---------|
| `fonts/NotoSans-Regular.ttf` | [Noto Sans](https://github.com/notofonts/latin-greek-cyrillic) (Latin, Greek, Cyrillic) | SIL Open Font License 1.1 (`fonts/OFL.txt`) |
| `fonts/NotoSansMono-Regular.ttf` | [Noto Sans Mono](https://github.com/notofonts/latin-greek-cyrillic) | SIL Open Font License 1.1 (`fonts/OFL.txt`) |
| `fonts/NotoSansDevanagari-Regular.ttf` | [Noto Sans Devanagari](https://github.com/notofonts/devanagari) (notofonts) | SIL Open Font License 1.1 (`fonts/OFL.txt`) |
| `fonts/NotoSansSC-Regular.otf` | [Noto Sans CJK SC subset](https://github.com/notofonts/noto-cjk) | SIL Open Font License 1.1 (`fonts/OFL.txt`) |
| `ui-icons/*.svg` | [Lucide](https://lucide.dev) | ISC (`ui-icons/LICENSE-lucide.txt`) |
| `clipart/*/*.svg` | [Material Design Icons](https://github.com/Templarian/MaterialDesign-SVG) by Pictogrammers (gallery pictures) | Apache License 2.0 (`clipart/LICENSE-apache-2.0.txt`) |
| `ui-icons/flip-horizontal.svg`, `ui-icons/flip-vertical.svg` | Drawn for LightCreator in the Lucide style | same license as LightCreator |

`icons/`, `lightcreator.ico` and `lightcreator.icns` are the LightCreator app icon in several sizes.
